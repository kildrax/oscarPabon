# 📰 Oscar Pabón – Personal Journalism Website  

This repository contains the source code for [oscarpabon.com](https://www.oscarpabon.com/), a personal journalism blog built for **Oscar Pabón**, a Colombian journalist. The site was created as a fully custom WordPress theme with JavaScript, CSS, and SCSS to ensure flexibility, performance, and a clean reading experience.  

## 🎯 Purpose  
The website functions as a digital space for journalistic content, organized into three main categories:  
- **Historical & Cultural** – Articles focused on history, traditions, and cultural reflections.  
- **Environment** – Content about environmental issues and sustainability.  
- **Other Authors** – Guest contributions and collaborations.  

New articles are published weekly, making the blog a continuously updated source of insights and analysis.  

## 🚀 Tech Stack  
- **WordPress** – Core CMS  
- **Custom Theme** – Built from scratch specifically for this project  
- **JavaScript** – For custom interactions  
- **CSS & SCSS** – Styling and responsive design  

## 🌍 Deployment  
The website is hosted on **DreamHost**, with weekly content updates and ongoing design improvements.  

## 📂 Repository Structure  
```plaintext
/assets        -> Images, icons, fonts  
/css           -> Compiled CSS files  
/scss          -> Source SCSS stylesheets  
/js            -> Custom JavaScript functionality  
/theme         -> WordPress custom theme files
```
